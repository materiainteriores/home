# Materia Interiores de Lujo

Landing page estática para **Materia Interiores de Lujo**, negocio especializado en estuco veneciano, microcemento y acabados premium para interiores.

Compatible con **GitHub Pages** — 100% HTML, CSS y JavaScript vanilla. Sin frameworks, sin bases de datos, sin backend.

## Tecnologías

- HTML5 semántico con SEO (Open Graph, Twitter Cards)
- CSS3 (Flexbox, Grid, variables, media queries, animaciones)
- JavaScript vanilla (Intersection Observer, smooth scroll)
- Google Fonts (Montserrat + Cinzel)

## Estructura

```
home/
├── index.html          # Página principal
├── README.md           # Documentación
├── AGENTS.md           # Instrucciones para agentes AI
└── assets/
    ├── css/styles.css  # Estilos
    ├── js/script.js    # Interactividad
    └── img/            # Imágenes, logo y favicon
```

## Uso

Abrir `index.html` en cualquier navegador o servir con un servidor estático:

```bash
npx serve .
# o
python3 -m http.server
```

## Despliegue en GitHub Pages

1. Subir el repositorio a GitHub
2. Ir a **Settings > Pages**
3. Seleccionar branch `main` (o `master`) y carpeta root (`/`)
4. Listo — se despliega automáticamente en `https://<usuario>.github.io/<repo>/`
